Validated versions: Minecraft 1.21.1 / NeoForge 21.1.233 / Java 21. Current stable AUTO release: 1.0.4.

Friends server: `practically-strung.tun.ply.gg:2077`. Friends need the Minecraft pack only; they do not install or sign in to Playit.

The AUTO launcher checks the public stable channel before each game launch and applies validated compatible pack updates.

The 1.0.4 archive includes bootstrap protocol 1. It checks updater/manifest.json before running the versioned engine, verifies its size and SHA-256, and then applies the pack update.
